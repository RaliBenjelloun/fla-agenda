# fla-agenda

Calendrier .ics auto-mis à jour des matchs d'une équipe Football Loisir Amateur.

- Source : https://football-loisir-amateur.fr/teams/7
- Lien d'abonnement : `https://raw.githubusercontent.com/RaliBenjelloun/fla-agenda/main/calendars/7.ics`
- Mise à jour : GitHub Action quotidienne (`.github/workflows/update.yml`). Lancement manuel : onglet Actions → Run workflow.
- Ajouter une équipe : mettre son id dans `TEAM_IDS` (ex. `"7,12"`).
